# PMS 系统使用手册

> 本手册面向企业员工、项目经理和系统管理员。应用里的「使用手册」页签与左侧导航同构，点击目录可以跳到对应模块。
>
> **当前基线**：PMS v1.0.0，运行时使用 OceanBase MySQL 兼容模式，数据库迁移为 V1–V12。本页包含 12 个功能模块；业务规则和前端设计规范通过「文档中心」进入独立页面。正文滚动时目录会自动高亮并同步 URL，点击目录仍可直接定位。

## 1. 阅读约定

- **员工**：主要使用工作台、项目列表、项目详情和顶栏搜索 / 通知。
- **项目经理**：在项目详情维护资料、节点、任务、里程碑、成员和关注人。
- **管理员**：在配置管理维护人员、组织、角色、批量导入和审计日志。
- **邮箱为唯一登录凭据核心**：中文名、英文名只用于展示。邮箱登录不区分大小写。
- **组织负责人和员工主归属独立**：组织负责人描述“谁负责这个组织单元”；员工主归属描述“员工的主岗位”，两者不会互相覆盖。

## 2. 截图、GIF 和操作视频

使用手册每个模块都可以挂媒体卡片。简单功能用一张当前界面截图；复杂操作只有在真实录屏准备好后才放视频，不放占位视频。

### 2.1 素材目录

把文件放进前端项目的 `public/manual/`，页面按静态资源读取：

```text
public/manual/
├── quick-start-login.png
├── workbench.jpg
├── project-list.jpg
└── organization-canvas.jpg
```

仓库附带的是脱敏演示截图，演示身份只用 `张伟` / `Alex.Zhang` / `alex.zhang@example.com`。当前版本不放置占位视频，避免把示意动画误认为实际操作。企业部署后应换成自己的脱敏素材。不要在图里露出密码、Token、验证码或不必要的个人信息。

截图推荐 PNG/JPG。视频推荐 MP4 或 WebM，且只有真实录屏才填写 `video` 插槽的 `src`。

### 2.2 页面接入

`src/views/manual/index.vue` 的 `media` 数组就是清单。只有配置了真实 `src` 的媒体才会渲染；没有真实截图或录屏的模块会省略媒体区，不展示占位卡片。

## 3. 快速开始

1. 使用管理员邀请时登记的邮箱登录。邮箱不区分大小写。
2. 本机默认是邮箱加密码。管理员启用 OIDC 或 LDAP 后，登录页才会出现对应按钮。
3. 登录后看右上角：姓名、中文 / English、搜索框和通知铃。
4. 顶栏搜索至少输入两个字，可在权限范围内查找项目、任务、里程碑和评论。点里程碑会打开该项目协作的里程碑页签。
5. 通知铃收录任务指派、任务/项目评论（关注人也会收到项目评论），以及节点完成、回滚。带节点的通知会打开对应流程节点。
6. 修改密码成功后必须重新登录。重启后端也会让已有登录失效。

中文名和英文名可以只填一个。没有英文名时展示中文名；没有中文名时用邮箱本地部分兜底。

## 4. 工作台

工作台是个人入口。数据来自 `GET /workbench`，只包含当前账号有权限看到的任务、项目和动态。

1. 工作概览：待处理、进行中、近 7 天到期、参与项目。
2. 我的任务：点击任务行打开所属项目，并直接进入该任务详情。
3. 项目进展：状态、进度、业务线路径、项目经理。
4. 最近动态：点击项目名称回到该项目的动态页签。
5. 部分接口失败时点刷新；已加载成功的内容会保留。

工作台不直接改项目、任务或里程碑。编辑请进入项目详情。

## 5. 研发管理

左侧一级页签「研发管理」下面，**本版本只有「项目管理」**。没有需求管理、测试管理或缺陷管理入口。

收起一级页签只是收起菜单，当前页面不会丢。研发管理面向交付，配置管理面向组织与权限，不要混用。

本版本还包含组织变更历史、导入失败状态和错误行下载能力；它们分别在组织架构和批量导入模块中说明。需求管理、测试管理和缺陷管理仍未上线。

## 6. 项目管理

### 6.1 项目列表

1. 用项目名称搜索，或按状态筛选。
2. 列表展示业务线路径、项目经理、状态、优先级、进度、任务数、成员数和两行周期。
3. 这些字段与项目详情读同一条项目记录。
4. 移动端表格可以左右滑动。

### 6.2 新建项目

列表上的「新建项目」先填名称、描述、优先级和项目排期。业务线、项目经理、成员和关注人在启动节点的资料区补全。

业务线要选到组织树的最低层。若该组织已设负责人，当前节点负责人会自动带出；必要时系统会先把该人加入项目成员。

### 6.3 项目详情

- **项目流程**：按节点推进。完成当前节点会解锁下一节点；回滚需要原因，之后的节点回到未开始。
- **节点负责人 / 节点排期**：和当前节点放在同一行。节点负责人不是组织负责人。
- **任务看板**：只显示当前节点的待办、进行中、已完成。点开任务可看子任务、任务评论和图片/PDF 附件（单文件不超过 5MB）。
- **项目协作**：页签依次是里程碑、甘特、日历、成员、动态。
- **甘特 / 日历**：只读。纵轴是有工期的节点，不是里程碑。项目和节点用起止日画条；里程碑和有截止日期的任务落在当天。不能拖拽，也没有任务依赖。
- **关注人**：会收到项目评论；节点完成或回滚时也会收到站内通知。
- **终止 / 恢复**：页顶操作，必须填写原因，并写入审计日志。

## 7. 配置管理

配置管理包含人员与权限、组织架构、角色管理、批量导入、审计日志。子页签按当前账号权限显示；看不到入口时先核对角色和数据范围。

## 8. 人员与权限

1. 用「邀请员工」创建账号，必填邮箱，中文名和英文名可选。保存后复制激活链接。
2. 「归属」里主归属必须唯一；兼职/项目归属可以有多条，不会覆盖主归属。
3. 「角色」添加或移除角色。实际可见范围还取决于数据范围。
4. 停用会立刻结束登录会话，但保留项目历史和审计记录。

改员工主归属不会自动改组织负责人，反之亦然。

## 9. 组织架构

1. 按住空白区域拖拽平移。右上角可以缩放、回到 100%，或点「适配」把整棵树放进视口。
2. 点击节点查看编码、类型、负责人、直属人数。
3. 新增时先选上级（不选则在顶层），再填编码、名称和类型。
4. 指定负责人只改组织字段，不会改该员工的主归属。
5. 根组织不能停用。停用前先迁移人员和项目归属。

## 10. 角色管理

1. 填写中文名称和编码。编码保存时转成大写，页面用小写展示。
2. 勾选权限点：人员、组织、角色、导入、审计、项目的读/写。
3. 数据范围：仅本人、本人及下属、本组织、本组织及下级、自定义组织、全公司。选自定义时还要指定组织。
4. 内置角色不能删除。分配后用目标账号验证页面和按钮。

不要靠隐藏前端按钮当鉴权。接口仍会校验权限点和数据范围。

### 10.1 角色能力矩阵

角色名称是给人看的中文文案，括号中的小写编码用于接口、审计和排障。实际授权结果始终是“功能权限 ∩ 数据范围”，以下是系统内置角色的默认边界：

| 角色 | 编码 | 主要功能权限 | 数据范围 |
| --- | --- | --- | --- |
| 超级管理员 | `super_admin` | 全量管理端权限 + `project:read/write` | 全公司（仍受服务端约束） |
| 项目管理员 | `project_admin` | `project:read/write` | 全公司项目数据 |
| 组织管理员 | `org_admin` | `admin:org:read/write`、`admin:user:read` | 本组织及下级 |
| 业务线负责人 | `business_owner` | 负责业务线的 `project:read/write` | 本组织及下级 |
| 部门负责人 | `dept_manager` | 负责部门的 `project:read/write` | 本组织及下级 |
| 项目经理 | `project_manager` | 负责项目的 `project:read/write` | 本人负责或参与的项目 |
| 普通员工 | `member` | 被授权项目的 `project:read` | 本人 |

管理员调整角色后，应使用目标账号分别验证“能看到什么”和“能修改什么”，并在审计日志中确认变更。后端接口是最终鉴权边界，前端隐藏菜单不能扩大权限。

## 11. 批量导入

1. 先选组织或员工，再下载当前模板。
2. 上传 `.csv` 或 `.xlsx`。页面不接收 `.xls`。
3. 预览校验。有错误先下载错误行，改完再上传。
4. 错误为零后再提交。结果未知时不要连点两次。

员工邮箱是幂等键。主归属和组织负责人是不同字段。

导入提交采用全有全无事务；失败批次会自动回滚，不会留下半批数据。提交成功后如需修正，走人员页、组织页，或按运行手册处理。组织调整、停用账号、主归属变化和导入结果都会进入审计日志。

## 12. 审计日志

可按动作、资源类型、资源 ID、操作人 ID 和时间筛选。请求 ID 显示在表格里，**不是**筛选项。

展开「查看差异」对照变更前后值。反馈问题时带上页面 URL、操作时间和请求 ID。不要把密码或 Token 写进工单。

## 13. 反馈中心

反馈中心用于跨项目收集问题、建议和体验反馈，与项目评论分开。所有提交人必须先登录；反馈可以独立提交，也可以关联项目、任务或节点。

1. 点击左侧「反馈中心」→「提交反馈」，填写标题、详细内容、类型和优先级；必要时补充关联项目、来源模块和页面地址。
2. 提交后记录工单号。反馈会进入「待初步处理」，列表支持按编号、类型、优先级和状态筛选。
3. 打开反馈详情查看当前负责人、项目上下文和处理记录。具备管理权限的人员可在抽屉中分派负责人、调整优先级、填写处理说明并推进状态。
4. 处理流程为「待初步处理 → 已分派 → 处理中 → 待确认 → 已解决 → 已关闭」。拒绝、重复反馈和无法复现必须填写处理说明。
5. 如果处理结果仍需继续跟进，提交人或管理员可对已解决、已关闭或异常反馈执行「重新打开」。

反馈标题、正文和处理说明不得包含密码、Token、验证码或未经脱敏的个人信息。提交和每次处理变更都会留下反馈历史与操作审计。

## 14. 常见问题

### 登录失败或突然回到登录页

提示「无法连接后端服务」表示本机后端没在跑或代理连不上。提示「邮箱或密码错误」才是账号问题。突然被踢回登录页通常是会话过期或后端刚重启。仍失败时把时间和请求 ID 交给管理员查日志。

### 左侧入口不见或按钮不可用

配置管理子页签按权限隐藏。先确认角色、数据范围和账号是否被停用。

### 人员主归属没有按预期变化

确认改的是员工主归属，不是组织负责人。保存后刷新列表。

### 业务线负责人没有自动带出

确认选到了最低层业务线，并且该组织已经设置负责人。

### 搜索没有结果

至少输入两个字。搜索只返回当前账号有权看到的项目、任务、里程碑和评论。

### 项目列表和详情不一致

先刷新并核对该项目 ID，再看审计日志。

### 导入结果不确定

不要再点提交。先下载服务端错误报告并修正原文件；如果提交已经失败，系统会自动回滚本批次。已成功提交的批次不需要重复提交，后续修正走人员或组织页。

## 15. 安全提醒

- 生产环境使用强 JWT 密钥、HTTPS、受限 CORS 和企业邮件。
- 不要使用默认密码；改密后重新登录。
- 截图、GIF、视频、日志和工单里不要出现密码、Token、验证码。
- 敏感操作完成后检查审计日志。数据库问题先留证据，再按恢复流程处理。
