# 看板演示就绪需求

## 看板指标

- 主指标区保留“项目总数、待开始、进行中、已完成”四张卡片。
- “已终止”保留为卡片下方的次级可点击统计，点击后筛选已终止项目。
- “需重点关注”不再占主指标卡片；重点关注项目区块标题行继续显示该数量。
- 主卡片的筛选行为、筛选状态和无障碍 pressed 状态保持一致。
- 大屏四列，中屏及窄屏两列，不产生页面横向溢出。

## 本地演示数据

- 仅写入已确认的本地 development MySQL 数据库，不修改已有项目或流程模板。
- 新增 8 个可辨认、可筛除的合成项目，名称以“【演示】”开头。
- 绑定本地当前通用项目默认发布流程；按其 9 个节点生成一致状态链。
- 5 个进行中项目分别停在第 1 至第 5 个不同节点；另外各 1 个项目处于未开始、已完成、已终止。
- 进行中节点之前均为已完成，当前节点为进行中，之后均为未开始；未开始项目全部节点未开始，完成项目全部节点已完成，终止项目有且仅有一个终止节点。
- 每个项目的组织、项目等级、优先级、经理、成员、关注人和项目日期有合理差异；所有信息均为虚构。
- 通过事务写入并以数据库及看板 API 只读核验，不删除或覆盖现有记录。
