# 流程模板组件库统一筛选规范

## 目标

统一流程模板配置页左侧组件库，让公共字段、绑定字段和业务工作台三类内容边界清晰，同时支持按业务对象筛选候选项。

## 组件库结构

左侧组件库固定分为三段，顺序不可变：

1. **公共字段**
   - 单行文本、数字、单选、日期、附件等字段控件直接展示。
   - 不提供数据来源筛选。
   - 这些控件代表节点自己的可配置字段，不属于项目、需求、专题或故事的已有数据。
2. **绑定字段**
   - 提供一个下拉筛选，选项顺序为：项目字段、需求字段、专题字段、故事字段、全部字段。
   - “全部字段”只代表上述四类绑定字段的并集，不包含公共字段。
3. **业务工作台**
   - 提供一个下拉筛选，选项顺序为：需求工作台、项目工作台、专题工作台、故事工作台、全部工作台。
   - “全部工作台”只代表业务工作台候选组件的并集，不包含公共字段或绑定字段。

## 专题字段与专题工作台

两者是不同的组件类型，不能共用标签、筛选分组或运行时键：

- 专题字段：专题名称、专题负责人、关联项目、状态、进度、最新构建版本、测试状态等只读数据绑定字段；“关联项目”以专题关联项目名称展示。
- 专题工作台：专题列表、故事拆分、专题交付等业务组件。已有的业务验收、发布与交接、价值复盘、知识沉淀等共享工作台通过 `workbenchTypes` 归入专题工作台；本次不新增同义运行时键，也不改变已有组件键。

专题字段通过 `topic.*` 绑定键识别；专题工作台通过独立的运行时组件键识别。

## 筛选与画布规则

- 筛选只改变左侧候选列表。
- 已添加到节点画布的公共字段、绑定字段和业务工作台不会因筛选切换而删除、隐藏、重排或修改。
- 当前流程类型的可用性规则仍然生效；来源筛选是在流程类型过滤之后再进行过滤。
- 已添加的内容不能因为切换筛选而丢失或产生重复添加；候选列表可以隐藏已经添加的绑定字段，但不得通过筛选状态修改画布内容。
- 没有候选项时显示对应类别的空状态，不影响画布内容。

## 兼容性与文案

- 已发布模板和草稿中的现有 `project.*`、`requirement.*`、`topic.*`、`story.*` 绑定键必须原样加载和保存。
- 旧模板中的字段顺序、字段属性、业务工作台顺序和配置不能因左侧筛选改造而变化。
- 中英文文案、下拉框可访问名称、空状态和画布上的来源标识需要同步更新。
